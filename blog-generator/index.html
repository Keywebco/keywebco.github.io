Blog Generator

Write a post by talking or typing — plain questions guide it, a named Federation mind helps you draft, and the truth gate stands between the draft and the publish-ready stamp. The finished post is a page: embed it, download it, print it, share it.

No drag-and-drop anywhere. Every field is labelled, dictation buttons sit under the writing boxes, and the post rebuilds itself live as you write. It is shaped the Federation way: the story first, then the idea in plain common sense, then the system already built, then a small invitation to try it.

1Write the post

Four layers, in order. You do not have to fill every layer — but the story layer is where a post begins, and the gate in step 3 asks for it.

Dictation uses your browser's own speech service. In Chrome and Edge your voice is sent to that company's servers to be turned into text; in Firefox it stays on your device. If no dictate button works on your browser, typing works everywhere.

Statements the post makes — each one gets a truth label

DIR-000: a claim is a FACT only when it is verified. Otherwise it is an INFERENCE, an ASSUMPTION, or honestly UNKNOWN. A statement with no label holds the whole post at the gate. The labels print on the finished post, next to each statement.

What the finished post carries

Honest note: the tools suite is its own page, being built alongside this generator. The embed line is written into your post now, in the same one-line shape as every Federation embed — and the tool space on the post stays empty until the tools page is published at the address above.

2Write with a Federation mind

Pick a mind, ask it for help, and its draft help lands in the box below — labelled with its name, so the reader of the draft always knows who suggested what. Put the help into a layer when you want it; rewrite it in your own words.

Said plainly: these helpers live on this page. They offer starters, questions and plainer phrasings from each mind's viewpoint — they are not live calls to an AI, and nothing here pretends otherwise. When the Federation API connection lands, these same buttons will ask the real minds.

3The truth gate

Nothing earns the publish-ready stamp until the gate is passed. The gate is checked live, below — and if the post changes after it is stamped, the stamp comes off and the gate must be passed again. A post that has not passed carries a DRAFT banner on its face, so no reader is ever fooled.

    Fresh facts — the live web search updater

    Before a post goes out, the updater is meant to search the live web for what is new on its subject — fresh facts offered with their source and date, labelled INFERENCE until they pass this same gate, and never silently written in as fact.

    4Your post, live

    This is the finished post itself, working — try its buttons: Print, Large print, the kid-safe switch, and Aether in the corner. It rebuilds as you change anything above, and it shows the DRAFT banner until the gate in step 3 is passed. (Its Print button works when the post stands on its own; some frames block printing, and the post will tell you if yours does.)

    5Take it with you

    Embed it anywhere

    Upload the downloaded post to your site, then paste this one line wherever the post should appear. That is the whole installation — the same shape as every Federation embed.

    The RSS entry

    One entry for the blog's feed, ready to paste into the RSS file beside the other posts.

    Share it — caption drafts

    The post itself carries Open Graph tags, so a link pasted into Facebook, WhatsApp or Threads builds its own preview card. These drafts go with it — edit them freely. Medium is paste-by-hand: its API closed to new integrations in 2023, so download the Markdown and paste it into a new Medium story; anyone who promises automatic Medium posting is selling a workaround Medium does not bless.

    Download the post in four forms

    HTML is the post itself, a finished page. Markdown is the same words as a document — and the form to paste into Medium. YAML is the post's facts, in the simple shape the lattice can read. The RSS entry downloads on its own above.

    6Check this post

    Source code examination: the generator reads the finished post's own code back and reports, in plain words, anything wrong or missing — an unlabelled claim, a share tag that is not there, a layer left empty.

    What is not connected yet — said plainly

    Live web search: the updater is a labelled hook in this version. It does not search and does not invent results; when it is connected, fresh facts will arrive with source and date and pass through the truth gate like everything else.

    Live co-writing: the minds in step 2 are on-page draft helpers — starters and questions in each mind's viewpoint, honestly labelled. Live calls to the Federation's AIs join these same buttons when the API connection lands.

    One-click publish to GitHub Pages: not wired in this version. The v1 path is: pass the gate, download the HTML, upload it, copy the embed line. Publishing stays Roger's word — the generator never publishes on its own.

    Tool embeds: the embed line is written into the post now; the tool itself appears when the Federation tools page is published at the address you set in step 1.

    Talking to the author: the panel is on every post that carries it; the author's live Sim answers there once the API connection lands. Today the panel says exactly that.
